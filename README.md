# GreenVinylGraphics

GreenVinylGraphics is a modern web application offering precision-designed digital templates for vinyl cutting, digital mockups, and graphic design projects. Specializing in templates for Apple devices, the platform ensures users have the tools needed to create stunning designs efficiently.

## Highlights

- **Performance**: Utilizes modern web technologies inclusing SSR to ensure fast load times and smooth user interactions.
- **Scalability**: Built with a modular architecture to accommodate future growth and feature expansions.
- **Maintainability**: Emphasizes clean code practices and comprehensive documentation for ease of maintenance.

## Tech Stack

| Category           | Technology              |
| ------------------ | ----------------------- |
| Framework          | Next.js 14              |
| Language           | TypeScript              |
| Styling            | Tailwind CSS 3.4.4      |
| UI Components      | Shadcn/ui               |
| Code Quality       | ESLint, Prettier        |
| Database           | Drizzle ORM, PostgreSQL |
| Payment Processing | Stripe                  |
| File Uploads       | UploadThing             |
| Email Services     | React Email, Resend     |

## Core Features

- **Product Catalog**: Browse a wide range of digital templates with detailed descriptions and high-quality images.
- **Shopping Cart**: Add desired products to the cart with real-time updates and seamless user interactions.
- **Secure Payments**: Integrated with Stripe for secure and efficient transactions.
- **Responsive Design**: Optimized for various devices, ensuring a consistent experience across desktops, tablets, and mobiles.

## Architecture Overview

GreenVinylGraphics employs a modern web architecture:

- **Application Layer**: Built with Next.js 14, providing server-side rendering for improved performance and SEO benefits.
- **Styling**: Tailwind CSS ensures a consistent and responsive design language.
- **UI Components**: Utilizes Shadcn/ui for accessible and customizable components.
- **Database**: Drizzle ORM with PostgreSQL manages data storage and retrieval.
- **Payments**: Stripe integration facilitates embeded secure payment processing.
- **File Uploads**: UploadThing handles efficient and secure file uploads.
- **Emails**: React Email and Resend manage email templates and delivery.

## Challenges & Solutions

- **Payment Integration**: Seamlessly integrated Stripe to handle secure transactions, ensuring user trust and compliance with payment standards.
- **File Uploads**: Implemented UploadThing to manage content efficiently, ensuring data integrity and security.
- **Email Delivery**: Combined React Email with Resend to ensure reliable and customizable email communications with users.
